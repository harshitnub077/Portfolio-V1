# Harshit Kudhial — Portfolio V1

Personal portfolio website built with **Next.js 15 (App Router)**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

## 🚀 Overview

- **Profile & Bio**: AI/ML Engineer specializing in Agentic RAG architectures, LLM systems, and high-performance kernel & cloud security.
- **Open Source Showcase**: 30+ merged contributions across Linux Foundation Zephyr RTOS and CNCF Kubescape.
- **Featured Projects**: Agentic AI applications including Cognify, NotForgotten, and BidForge.
- **Experience Timeline**: FlyRank AI, Product Manager Accelerator, Linux Foundation, CNCF, and Newton School of Technology.
- **Live GitHub Activity**: Real-time GitHub contribution graph integration and metrics.
- **Command Palette**: Interactive quick menu (`⌘K`).

## 🛠️ Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React & React Icons (Simple Icons)

## 💻 Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site locally.
